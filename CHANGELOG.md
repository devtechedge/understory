# Changelog

All notable changes are recorded here. The format follows Keep a Changelog
and the project uses semantic versioning.

## [1.0.0] - 2026-10-24

### Added

- A persistent browser vitrine with three species: cushion moss, maidenhair
  fern, and ghost fungus.
- Deterministic growth, dormancy, recovery, moss spread, fern propagation by
  cutting, and ghost fungus sporulation.
- Care controls for light, moisture, season, pause, and a six-hour time-lapse
  preview.
- A layered Canvas 2D diorama with a warm lamp room, daylight room, loupe,
  specimen cards, soil card, ambient motion, and reduced-motion Still mode.
- An automatic field journal and a herbarium that presses mature specimens.
- Seed-packet JSON export and import with bounded validation.
- IndexedDB persistence with a localStorage fallback and two-hour offline
  catch-up.
- Keyboard controls, focus-trapped dialogs, skip link, canvas alternative text,
  and mobile planting controls.
- A Vite 7, React 19, and TypeScript 5 build with self-hosted Fontsource
  variable families.
- Vitest simulation coverage, Playwright journeys, axe accessibility checks,
  and a production smoke script.
- Split CI jobs, dependency review, CodeQL, Dependabot, and a security policy.
